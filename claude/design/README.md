# Design reference (E2 theme)

Static HTML snapshots exported from the design canvas, 1440px wide.
They are a **visual reference, not a layout spec**: never copy their fixed px sizes.
Rules, tokens and fluid layout live in `../DESIGN.md`.

- `e2-flat.html`, `e2-shaded.html`: homepage hub (choose one)
- `pages/about.html`: /about
- `pages/projects.html`: /projects ("My Work")
- `pages/project-clinic-os.html`: /projects/clinic-os (case study template)
- `pages/experience.html`: /experience
- `pages/recommendations.html`: /recommendations
- `pages/blog.html`, `pages/blog-post.html`: /blog and a post (older layout, recoloured; owner will restyle)

Images reference the repo's existing `public/` paths and load under `npm run dev`.
